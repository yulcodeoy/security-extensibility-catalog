# Microsoft Security Extensibility Catalog

An unofficial field guide to the extensibility surfaces (APIs, connectors, SDKs, PowerShell)
across the Microsoft Security portfolio — Defender, Entra, Purview, Intune, Sentinel,
Security Copilot, Agent 365 and SharePoint/M365.

**[Open the catalog](https://yulcodeoy.github.io/security-extensibility-catalog/)**

- 354 surfaces, 101 partner scenarios, 9 product families
- Filter by product, operation (read vs. write/modify), access method, maturity and skill profile
- A cross-product **Connections** view showing where the portfolio genuinely overlaps

## Disclaimer

This is a personal working reference, **not an official Microsoft publication**, and is not
endorsed by Microsoft. Portions were drafted with AI assistance and reviewed against public
Microsoft Learn documentation. Vendor and product names are referenced as documented public
product facts. **Always verify each surface against its linked Microsoft Learn page before
relying on it.**
